From now on the Log sends each such change to Skills as it happens. This file is the backlog from Run 1 of a pilot run, in the order the changes were made. Each entry gives the owner's order (paraphrased here; a real group quotes it verbatim), what changed, where it lives now, and a build hint. Skills decides what to build.
