# Structural and tooling errors a new spin-up would repeat — for Skills' setup store

**Why — the owner's order, in short:** the structural, project-agnostic errors and rules found here would be repeated by any new spin-up of the structure, so send them, anything like them, and anything else applicable to Skills, for the setup store.

Each entry is a problem the Log hit in Run 1 of a pilot run that has nothing to do with that run's subject. Every row gives what went wrong, the cause, the fix already made (and where it lives), and a test built from the recorded instance. It adds to CHANGES-FOR-SKILLS.md (rules and orders); this file is about mechanics. Skills decides what to build. The fixes are already in the plugin's `scripts/` (seats 0.1.1), except where marked.
